# Биржа

Биржа — это торговая площадка для обмена монеток на жетоны, которые приобретаются за реальную валюту на официальном сайте сервера. Система позволяет игрокам торговать между собой игровой валютой.

## Как открыть биржу

Меню биржи доступно по команде `/exchange`

## Как обменять жетоны на монетки

### Экспресс

Обменять жетоны на монетки можно быстро и просто. Для этого нужно ввести команду `/exchange buy <количество монеток>`. Укажите, сколько монеток вы хотите получить, и система автоматически найдет выгодный обмен и обменяет ваши жетоны на нужное количество монет.

{% hint style="info" %}
Пример использования команды `/exchange buy`

* `/exchange buy 100000` — вы получите 100.000 монеток за свои коины

Дабы упростить указание количества монеток, вы можете использовать следующий способ:

* Указание цены при помощи букв: 1k — 1000 монеток, 1kk — 1 000 000 монеток, 1m — 1 000 000 монеток. Пример: `/exchange buy 5kk` — вы получите 5 000 000 монеток;
{% endhint %}

### Маркет

<div data-with-frame="true"><figure><img src="../.gitbook/assets/exchange_market (2).png" alt=""><figcaption></figcaption></figure></div>

Обменять жетоны на монетки можно в главном меню биржи `/exchange`. Выберите желаемую заявку и нажмите по иконке заявки. Вы можете выкупить как все сразу монетки, так и выкупить только часть монеток.

{% hint style="info" %}
В главном меню биржи заявки сортируются по выгодности. Сначала показываются те, где за один коин предлагается больше всего монеток.
{% endhint %}

## Как обменять монетки на коины

<div data-with-frame="true"><figure><img src="../.gitbook/assets/exchange_sell (1).png" alt=""><figcaption></figcaption></figure></div>

Обменять монетки на жетоны можно в главном меню биржи `/exchange`. Для этого нужно создать заявку на продажу монет, нажав на специальную иконку в меню. У вас откроется меню с выбором, сколько вы хотите получить жетонов.
