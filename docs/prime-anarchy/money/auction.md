# Аукцион

Аукцион — это торговая площадка для продажи и покупки игровых предметов.

## Как открыть аукцион

<div data-with-frame="true"><figure><img src="../.gitbook/assets/ah-main.png" alt=""><figcaption><p>Главное меню Аукциона /ah</p></figcaption></figure></div>

Меню аукциона доступно по команде `/ah`

## Как купить предмет

<div data-with-frame="true"><figure><img src="../.gitbook/assets/ah-item (1).png" alt=""><figcaption><p>Пример, как выглядит товар на Аукционе</p></figcaption></figure></div>

Чтобы приобрести предмет, сначала выберите желаемый лот в меню аукциона `/ah`. Нажмите на иконку желаемого лота. Если у вас достаточно монеток, покупка будет успешной.

## Как продать предмет на аукционе

Чтобы продать предмет, сначала возьмите продаваемый предмет в руку, далее пропишите команду `/ah sell <цена>`.

{% hint style="info" %}
Если вы желаете, чтобы ваш товар купили полностью, вы можете указать в конце `full`. Пропишите команду `/ah sell <цена> full`. Все товары, которые можно купить только полностью, помечаются специальной строчкой в описании лота.
{% endhint %}

### Как снять предмет с продажи

Чтобы убрать предмет с продажи, откройте меню аукциона `/ah`, далее нажмите по иконке «Товары на продаже». В открывшемся меню будут отображаться все товары, которые вы продаете сейчас.

### Как увеличить количество слотов для  продажи

Чтобы увеличить количество слотов под продажу, откройте меню аукциона `/ah`, далее найдите иконку «Помощь по маркету». Здесь вы можете посмотреть, сколько вам доступно слотов, а также, имея при себе гемы, прикупить доп. слоты.

{% hint style="info" %}
Минимальная цена за один доп. слот на аукционе – 149 гемов.
{% endhint %}

## Поиск нужного предмета

### Поиск по названию

Чтобы найти на аукционе `/ah` нужный вам предмет, вы можете указать его название при помощи команды `/ah search <название>`.

### Поиск по игрокам

Чтобы узнать, какие предметы продает игрок на аукционе `/ah`, вы можете прописать его ник при помощи команды `/ah player <никнейм>`.
