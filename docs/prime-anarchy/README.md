# О режиме Прайм Анархия

## Что за Прайм Анархия?

**Прайм Анархия** — это новая и особенная Анархия на версии **Minecraft 1.21.11**. Здесь вас ждёт совершенно новый взгляд на привычную Анархию — с **уникальными механиками, ивентами и возможностями**, которых не встретить на других режимах. И всё это уже на **новейшей версии Майнкрафт**

## Особенности Прайм Анархии

{% stepper %}
{% step %}
### Новейшая версия Майнкрафта

Весь режим заточен под новые версии Майнкрафта. Все механики новых версий, начиная от данжей Древнего города и Камеры испытаний до булавы с рассадником испытаний на Анархии.
{% endstep %}

{% step %}
### Новые визуальные эффекты

Прайм Анархия была разработана с использованием новых современных технологий, вас ждут впечатляющие эффекты, анимации и крутой визуал.
{% endstep %}

{% step %}
### Всё самое лучшее

Всё самое лучшее с Классик Анархии перешло на Прайм Анархию в новом и полностью улучшенном виде.
{% endstep %}
{% endstepper %}
