# Стаканье зелий

## Как стакать зелья

Зелья можно запросто соединить. Всё, что для этого нужно, — просто выбросить их на землю друг к другу и ваши зелья стакнутся.

## Какие зелья можно стакнуть

<figure><img src="../.gitbook/assets/bottle_stack (1).png" alt=""><figcaption></figcaption></figure>

Не все зелья можно стакнуть, а только из ниже перечисленных:

1. Зелье силы
2. Зелье скорости
3. Зелье регенерации
4. Зелье невидимости
5. Зелье огнестойкости
6. Ультимативное зелье

{% hint style="info" %}
В зависимости от типа зелий и от вашей привилегии количество зелий в стаке будет отличаться.
{% endhint %}
