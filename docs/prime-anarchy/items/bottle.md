# Стаканье зелий

## Как стакать зелья

Чтобы объединить зелья в стак, выбросьте их на землю.

## Какие зелья можно стакнуть

<figure><img src="../.gitbook/assets/bottle_stack (1).png" alt=""><figcaption></figcaption></figure>

Стакнуть можно только нижеперечисленные зелья:

1. Зелье силы
2. Зелье скорости
3. Зелье регенерации
4. Зелье невидимости
5. Зелье огнестойкости
6. Ультимативное зелье

{% hint style="info" %}
В зависимости от типа зелий и от вашей привилегии количество зелий в стаке будет отличаться.
{% endhint %}
