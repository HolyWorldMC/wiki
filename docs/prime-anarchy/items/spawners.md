# Рассадники

Рассадники (или "спавнеры") — это ванильные блоки спавнеров из майнкрафта, которые спавнят мобов вокруг себя, но изменены под реалии Прайм Анархии.

## Типы рассадников

| Тип                          | Радиус призыва | Количество мобов |
| ---------------------------- | -------------- | ---------------- |
| Обыкновенный рассадник       | 4 блока        | 1–4              |
| Рассадник испытаний          | 5 блоков       | 1–7              |
| Зловещий рассадник испытаний | 6 блоков       | 1–10             |

## Для чего нужны рассадники

Рассадники призывают вокруг себя мобов, которых можно убить и получить с них ресурсы. Радиус появления и количество мобов зависят от типа рассадника.

### Как открыть меню рассадника

<div data-with-frame="true"><figure><img src="../.gitbook/assets/spawner_menu.png" alt=""><figcaption></figcaption></figure></div>

Открыть меню рассадника (спавнера) можно нажатием правой кнопки мыши по стоящему рассаднику.

### Элементная работоспособность

<div data-with-frame="true"><figure><img src="../.gitbook/assets/spawner_fuel.png" alt=""><figcaption></figcaption></figure></div>

Рассадник испытаний и Зловещий рассадник испытаний для своей работы требуют подпитки в виде Элементов. 1 Элемент равен 1000 спавнов мобов, то есть за 1 Элемент рассадник заспавнит 1000 мобов.

{% hint style="warning" %}
Без подпитки в виде Элементов рассадник работать не будет.
{% endhint %}

## Как добыть рассадник

### Выполнить задания на его получение

<div data-with-frame="true"><figure><img src="../.gitbook/assets/spawner_pickup.png" alt=""><figcaption></figcaption></figure></div>

Абсолютно любой рассадник, стоящий где-то в мире, можно преобразовать в предмет, то есть переместить его в инвентарь.

{% stepper %}
{% step %}
#### Откройте меню рассадника и выберите категорию «Добыть рассадник»


{% endstep %}

{% step %}
#### Выполните задания, которые необходимы для добычи рассадника

У каждого типа рассадника свое количество заданий для выполнения:

1. Обычный рассадник — 3 задания
2. Рассадник испытаний — 5 заданий
3. Зловещий рассадник испытаний — 8 заданий

{% hint style="info" %}
Мобы делятся на обычных, редких, эпических и легендарных. Задания и предметы могут быть лёгкими, средними или тяжёлыми.
{% endhint %}
{% endstep %}

{% step %}
#### После выполнения всех заданий вы сможете забрать спавнер

<div data-with-frame="true"><figure><img src="../.gitbook/assets/spawner_complete.png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Найти рассадник в мире

В ванильных данжах «Камеры испытаний» спавнятся рассадники испытаний, которые вы можете спокойно добыть при помощи механики добычи рассадника.

{% hint style="info" %}
Чтобы добыть данный рассадник испытаний, вам потребуется гораздо больше усилий, чем для обычного рассадника.
{% endhint %}
