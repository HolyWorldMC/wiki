# Локации

**Локации** – это специальные структуры, разбросанные по острову Альфа СМП. Внутри локаций игроки могут добывать ценные ресурсы, сражаться с усиленными мобами и находить редкие предметы в контейнерах. Каждая локация имеет свои уникальные особенности, сложность и лут.

## Как попасть в локацию

Локации генерируются по всему миру в случайных местах. Чтобы узнать, какие локации есть поблизости или найти нужную, используйте команду `/gps`. С помощью навигатора вы сможете направиться в нужную сторону.

## Общие правила

* Локации нельзя приватить, ставить свой регион.
* Можно ставить лестницы и подмостки для более удобного перемещения.
* Часто в локациях спавнится топливо.

## Мобы

Кроме рассадников испытаний, мобы появляются в локациях и сами по себе. Состав зависит от локации.

| Локация                               | Кто появляется                                                                                           |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Деревня, Мельница, Маяк               | Зомби, скелеты, пауки                                                                                    |
| Промзона                              | Зомби, скелеты, пауки, пещерные пауки, криперы, чешуйницы                                                |
| Парящий Остров                        | Зомби, скелеты, пауки, пещерные пауки, слизни, криперы                                                   |
| Карьер, обе пещеры, Заброшенная шахта | Зомби, скелеты, болотные скелеты, пауки, пещерные пауки, слизни, криперы, утопленники, кадавры, зимогоры |
| Медный данж                           | Болотные скелеты, зомби, скелеты, вихри, чешуйницы, слизни, вексы, зимогоры                              |
| Бастион                               | Пиглины, брутальные пиглины, зомби-пиглины, ифриты, хоглины, магмовые кубы, скелеты-иссушители           |
| Крепость Энда                         | Эндермены, эндермиты, вексы, чешуйницы, скелеты, пауки, зомби, ведьмы                                    |

## Контейнеры

Лут лежит в контейнерах, и до каждого типа добираются по-своему.

| Контейнер                    | Как забрать лут                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Вазы**                     | Ломаются с одного удара, лут выпадает на землю.                                                         |
| **Сундуки**                  | Открываются как обычные. После закрытия сундук исчезает, а оставшийся лут выпадает на пол.              |
| **Бочки, полки, зельеварки** | Требуется нанести определённое количество ударов — сколько осталось, показывает голограмма.             |
| **Вагонетки**                | Нужно нанести фиксированное количество урона, голограмма отображает текущее ХП.                         |
| **Клады**                    | Особый тип контейнеров с высокой прочностью и лучшими ресурсами. В разных локациях выглядят по-разному. |

## Хранилища

Хранилища не ломаются — их открывают ключом. Ключ выпадает за прохождение рассадника испытаний, а внутри лежит лучший лут локации.

Ключ привязан к той локации, где выпал: в другой он не сработает. Уже открытое Хранилище повторно не открывается и восстанавливается через несколько часов.

Часть Хранилищ — <mark style="color:purple;">**Зловещие**</mark>: лут в них ценнее, а восстанавливаются они реже обычных.

Хранилища есть не везде — из описанных ниже локаций они встречаются только в Медном данже.

**Рассадники испытаний** – это особые спавнеры, расположенные внутри локаций. Они активируются при приближении игрока и выпускают несколько волн мобов. После прохождения испытания спавнер выдаёт ценный лут и уходит на перезарядку.<br>

## Утилизатор

<figure><img src="https://1639949389-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FlJRG84u5Trm5HJTxG951%2Fuploads%2FLqgBuFTOd7Wn3CrGbJpz%2Fimage.png?alt=media&#x26;token=fdb2f945-9f8d-495f-bd3f-74279dde2368" alt=""><figcaption></figcaption></figure>

В локациях можно встретить утилизатор - где вы можете переработать уже ненужные вещи: ваши инструменты, броню или оружие. Утилизатор перерабатывает ненужные предметы в исходный материал.

_Например,_\
_&#x416;елезные предметы - в железные слитки_\
_&#x410;лмазные предметы - в алмазы_

А также выпадают - <mark style="color:violet;">**аметисты**</mark>, которые вам понадобятся для прокачки утилизатора, спавнера, покупки новых слотов в эндер-сундуке и др. (см. главу _Аметисты_)

### <mark style="color:$success;">Деревня</mark> ★☆☆☆☆

<figure><img src="https://1639949389-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FlJRG84u5Trm5HJTxG951%2Fuploads%2FuVp9rpbo2sefq5ue1h9l%2Fimage.png?alt=media&#x26;token=561a1a17-248b-4eef-b19d-9dba7ba51b70" alt=""><figcaption></figcaption></figure>

<mark style="color:$success;">**Деревни**</mark> – это поселения, разбросанные по поверхности мира. В отличие от подземных локаций, здесь нет агрессивных мобов высокого уровня, а упор сделан на сбор базовых ресурсов, идеальное место для новичков.

В локации можно добыть пшеницу и морковь с грядки, а в домах найти кровати, которые можно сломать.

#### Контейнеры

Сундуки, бочки и вазы. Чаще всего содержат:

* Еду
* Базовые ресурсы
* Инструменты, броню и оружие низкого тира

### <mark style="color:$success;">Мельница</mark> ★☆☆☆☆

<figure><img src="https://1639949389-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FlJRG84u5Trm5HJTxG951%2Fuploads%2FtMOfo9nlzUevC4TL6alS%2Fimage.png?alt=media&#x26;token=492ec1be-7ca0-4291-927e-2a41379a9b5a" alt=""><figcaption></figcaption></figure>

<mark style="color:$success;">**Мельницы**</mark> – это небольшая локация, расположенная на поверхности. Здесь почти нет опасных мобов. Отличное место для новичков, чтобы быстро запастись едой и материалами для крафта.

Рядом с мельницей можно добыть пшеницу с грядки или найти стог сена — его тоже можно сломать ради пшеницы. В домах есть кровати, их можно сломать и поставить в разрешённом месте.

#### Рассадник испытаний

Кого спавнит, от частых к редким: свинья, овца, зомби, корова, курица, лошадь, железный голем, зомби-житель, паук. За прохождение чаще всего выпадает:

* Еда
* Аметисты
* Инструменты, броня и оружие низкого тира

#### Контейнеры

Сундуки, бочки и вазы. Чаще всего содержат:

* Еду
* Ресурсы для крафта
