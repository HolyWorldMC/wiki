# О режиме Альфа SMP

## Что за Альфа SMP

**Альфа SMP** — это выживание на одном большом острове, окружённом океаном. Здесь нет Ада и Края: весь контент собран на острове, а попасть куда-то ещё нельзя.

Главное отличие от обычного выживания — база здесь не стоит сама по себе. Приват нужно чинить и кормить ресурсами, иначе он развалится, а соседи могут прийти и взорвать его.

## Особенности режима

{% stepper %}
{% step %}
### Один остров вместо трёх миров

Ад и Край недоступны, но их обитатели никуда не делись: пиглины, ифриты и хоглины живут в Бастионе, а эндермены и вексы — в Крепости Энда. Чтобы добраться до незеритового снаряжения, нужно идти не в портал, а в локацию.
{% endstep %}

{% step %}
### Океан не выпустит

Остров ограничен морской границей. Пока вы рядом с берегом, всё в порядке, но чем дальше уплываёте, тем сильнее вода бьёт — и вернуться уже не выйдет.
{% endstep %}

{% step %}
### База, за которой нужно ухаживать

Приват — это блок-ядро с запасом прочности. Оно тратит ресурсы из своего слота, а блоки базы со временем гниют. Если не чинить и не пополнять — база разрушится сама, без всякого рейда.
{% endstep %}

{% step %}
### Рейды взрывчаткой

Чужую базу нельзя разобрать киркой — только взорвать. Динамит, C4, разрывные стрелы и трезубец-метатель открываются за очки, которые зарабатываются в игре.
{% endstep %}
{% endstepper %}

## С чего начать

{% stepper %}
{% step %}
### Осмотритесь и соберите базовые ресурсы

Ближайшие Деревни, Мельницы и Маяки — самые простые локации. Там лежат еда, инструменты и материалы для первого привата.
{% endstep %}

{% step %}
### Поставьте приват

Начните с железного блока: он дешёвый и защищает небольшую зону. Позже ядро можно сменить на алмазное или незеритовое.
{% endstep %}

{% step %}
### Не дайте базе сгнить

Держите в слоте привата топливо и чините блоки — кистью или через наковальню в меню региона.
{% endstep %}

{% step %}
### Подключите оповещения о рейде

Привяжите Telegram-бота через Барьер в меню привата, чтобы узнать об атаке, даже когда вы не в игре.
{% endstep %}

{% step %}
### Идите за снаряжением в локации

Команда `/gps` покажет, что есть поблизости. Чем больше звёзд у локации, тем опаснее мобы и тем ценнее добыча.
{% endstep %}
{% endstepper %}
