# Грузы

<figure><img src="../.gitbook/assets/image (73).png" alt=""><figcaption></figcaption></figure>

## Как не пропустить ивент

* До падения груза на остров вы услышите **звуки** самолета - это сигнал о скором приземлении груза.
* После приземления в **чат** приходит оповещение с примерными координатами груза.
* Как можно скорее найдите **место**, куда приземлился груз, заберите лут первым.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (82).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="danger" %}
Лутайте груз **только** в зачарованной броне и с большим запасом <mark style="color:yellow;">**золотых яблок**</mark>. Вокруг груза спавнятся блоки лавы и магмы, без нужной брони, вы не дойдете до контейнеров.
{% endhint %}

## Как получить лут

{% stepper %}
{% step %}
### Найдите груз по координатам из чата
{% endstep %}

{% step %}
### Нажмите ПКМ по любому контейнеру

Откроется меню взлома на **30 секунд.**\
![](<../.gitbook/assets/image (88).png>)
{% endstep %}

{% step %}
### Не закрывайте меню до окончания взлома груза

Если вы закроете контейнер раньше, чем взломете его – таймер сбросится до начала.
{% endstep %}

{% step %}
### После взлома быстро соберите весь полезный лут

У вас будет **10 секунд**, чтобы забрать предметы к себе в инвентарь, пока другим игрокам он недоступен. После 10 секунд, сундук становится доступным для всех.
{% endstep %}
{% endstepper %}
