# Навигатор

Заходя первый раз на остров, вы получаете особый предмет – <mark style="color:blue;">**навигатор**</mark>. С его помощью вы не заблудитесь и всегда сможете добраться до нужной локации. Вы можете забрать новый компас в инвентарь командой <mark style="color:blue;">**/gps**</mark>.

<figure><img src="../.gitbook/assets/image (86).png" alt=""><figcaption></figcaption></figure>

### Как пользоваться GPS

{% stepper %}
{% step %}
### Если вы хотите добраться до ближайшей локации

Возьмите в руку компас и ПКМ по нему, в чат придут координаты локации. А сам навигатор будет показывать направление этой локации.

<figure><img src="../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Если вы хотите найти определенную локацию

Команда /gps _{локация}_ изменит направление навигатора на другую нужную локацию.

<div align="left"><figure><img src="../.gitbook/assets/image (75).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Если вы хотите найти вашу кровать

Команда /gps _{название кровати}_ изменит направление навигатора на нужную кровать.

<div align="left"><figure><img src="../.gitbook/assets/image (80).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
После возрождения навигатор будет направлен на ваше **место смерти.**
{% endhint %}
