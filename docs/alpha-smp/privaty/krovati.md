## Как установить кровать

1. Поставьте кровать в разрешённом месте, она автоматически запомнится как ваша точка возрождения. Проверьте, достаточно ли это безопасное место.
2. Поставьте кровать так, чтобы над ней было свободное место для вашего телепорта.&#x20;
3. Можно переименовать кровать, зажав **shift + пкм**.

{% hint style="info" %}
Кровати можно ставить и **вне своего привата** – они не исчезнут со временем. Но нельзя ставить в чужом привате или в локациях.
{% endhint %}

После установки кровати на нее накладывается **задержка** до следующего респавна. Это значит, что вернуться после смерти на недавно установленную кровать нельзя. При телепорте на кровать в вашем привате, все кровати в этом регионе также блокируется на некоторое время.

Любая чужая кровать имеет <mark style="color:$success;">**40 HP**</mark>, и ломать ее можно всем.

## Как телепортироваться на свою кровать

{% stepper %}
{% step %}
### После возрождения нажмите на сообщение ТЕЛЕПОРТИРОВАТЬСЯ в чате

У вас есть 60 секунд после респавна, чтобы телепортироваться на свою кровать через сообщение в чате или, открыв меню через команду _**/beds.**_
{% endstep %}

{% step %}
### В открытом меню выберите нужную кровать

Доступная кровать для телепорта <mark style="color:$warning;">**желтого цвета**</mark>. Если время вышло, то телепорт станет недоступен, меню закроется.

<figure><img src="../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Телепортируйтесь на выбранную кровать

Важно, чтобы кровать стояла в свободном месте.
{% endstep %}
{% endstepper %}
