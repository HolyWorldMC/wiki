# Биржа

**Биржа** — это торговая площадка, где игроки могут обменивать монетки на жетоны, приобретённые за реальную валюту на официальном сайте сервера. Система позволяет игрокам торговать игровой валютой между собой.

## Как открыть биржу

<div data-with-frame="true"><figure><img src="../.gitbook/assets/exchange_main (1).png" alt=""><figcaption></figcaption></figure></div>

Меню Биржи можно открыть с помощью команды `/exchange`.

## Как обменять жетоны на монетки

### Экспресс

Обменять жетоны на монетки можно быстро и просто. Для этого достаточно ввести команду `/exchange buy <количество монеток>` и указать необходимое количество монеток. Система автоматически найдёт наиболее выгодный вариант обмена и обменяет ваши жетоны на нужное количество монеток.

{% hint style="info" %}
#### Пример использования команды `/exchange buy`

* `/exchange buy 100000` — вы получите **100 000 монеток** в обмен на свои жетоны.

Чтобы упростить указание необходимого количества монеток, можно использовать буквенные обозначения:

* `1k` — **1 000 монеток**;
* `1kk` — **1 000 000 монеток**;
* `1m` — **1 000 000 монеток**.

Например, `/exchange buy 5kk` — вы получите **5 000 000 монеток** в обмен на свои жетоны.
{% endhint %}

### Маркет

<div data-with-frame="true"><figure><img src="../.gitbook/assets/exchange_market (2) (1).png" alt=""><figcaption></figcaption></figure></div>

Обменять жетоны на монетки можно в главном меню Биржи `/exchange`. Выберите подходящую заявку и нажмите на её иконку. При этом вы можете выкупить **как всё доступное количество монеток сразу, так и только их часть**.

{% hint style="info" %}
В главном меню Биржи заявки сортируются по выгодности: в первую очередь отображаются те, в которых за один жетон предлагается наибольшее количество монеток.
{% endhint %}

## Как обменять монетки на коины

<div data-with-frame="true"><figure><img src="../.gitbook/assets/exchange_sell (1) (1).png" alt=""><figcaption></figcaption></figure></div>

Обменять монетки на жетоны можно в главном меню Биржи `/exchange`. Для этого создайте заявку на продажу монет, нажав на специальную иконку в меню. После этого откроется окно, где вы сможете указать, сколько жетонов хотите получить за свои монетки.
