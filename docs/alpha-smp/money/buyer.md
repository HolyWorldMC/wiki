# Скупец

Скупец — одна из ключевых особенностей режима, с помощью которой можно крайне выгодно продавать игровые ресурсы за валюту «монетки», а также выполнять ежедневные задания и постепенно увеличивать свой заработок.

## Как открыть Скупца

<div data-with-frame="true"><figure><img src="../.gitbook/assets/b_main (1) (1).png" alt=""><figcaption></figcaption></figure></div>

Меню Скупца можно открыть несколькими способами: с помощью команды `/b` или `/buyer`, а также через НПС на спавне, которого зовут «Скупец».

## Торговля

### Как продавать ресурсы

<div data-with-frame="true"><figure><img src="../.gitbook/assets/b_sell (2).png" alt=""><figcaption></figcaption></figure></div>

Продавать ресурсы можно во вкладке «Торговля» в главном меню Скупца `/b`. Здесь Скупец предлагает **15 различных товаров**, которые готов у вас приобрести. Найдите среди них нужный товар и нажмите по нему ПКМ, имея соответствующий ресурс в своём инвентаре.

{% hint style="info" %}
Торги делятся на две категории редкости: **обычные** и **особые**. От категории товара зависит, как часто он будет обновляться, а также сложность его добычи.

* **Обычные торги** обновляются **раз в 6 часов**.
* **Особые торги** обновляются **раз в 8 часов**.
{% endhint %}

{% hint style="success" %}
Имея при себе достаточное количество **Элементов** или **Гемов**, вы можете принудительно обновить ассортимент предложений Скупца.

* **обычные торги** можно обновить за **1 Элемент** или **49 Гемов**;
* **особые торги** — за **4 Элемента** или **69 Гемов**.
{% endhint %}

{% hint style="warning" %}
Скупец может принять у вас лишь **ограниченное количество каждого товара**. Узнать доступный объём для продажи можно, нажав на иконку соответствующего ресурса.
{% endhint %}

### Множители монеток

<div data-with-frame="true"><figure><img src="../.gitbook/assets/b_percent (2).png" alt=""><figcaption></figcaption></figure></div>

На многие товары может действовать **Множитель торговли**, который сделает их продажу ещё выгоднее. Множители бывают **трёх уровней**: I уровень даёт **+5%** к стоимости товара, II уровень — **+10%**, а III уровень — **+15%**.

Получить Множители торговли можно несколькими способами:

1. Имея при себе достаточное количество **Элементов**, можно приобрести **Множитель дня за 32 Элемента** или **Множитель недели за 128 Элементов**. Оба множителя действуют на определённую категорию товаров.
2. За **32 Элемента** можно приобрести **Случайный Множитель**. В этом случае случайно определяется категория, уровень и количество доступных стаков множителя.
3. Выполняя **Ежедневную сделку**, можно получить случайный Множитель в качестве награды.
4. За прохождение **Этапов Скупца** в качестве награды также можно получить Множители торговли.

{% hint style="success" %}
Множители не имеют ограниченного времени использования — они расходуются по мере продажи товаров, на которые действуют. Вы можете воспользоваться множителем в любое удобное время, пока не будет исчерпано доступное количество продаж для соответствующих категорий.
{% endhint %}

## Этапы и награды

<div data-with-frame="true"><figure><img src="../.gitbook/assets/b_page_and_rewards (1).png" alt=""><figcaption></figcaption></figure></div>

Этапы Скупца — это своеобразный боевой пропуск, где есть лишь одна главная цель — **зарабатывать монетки, торгуя со Скупцом**. С каждым новым этапом требования становятся всё выше, поэтому для продвижения дальше придётся заработать ещё больше монеток.

{% hint style="success" %}
За прохождение каждого этапа Скупца вы получаете ценное вознаграждение — от различных ресурсов до **Множителей торговли**.
{% endhint %}

## Ежедневная сделка

<div data-with-frame="true"><figure><img src="../.gitbook/assets/b_daily (1) (1).png" alt=""><figcaption></figcaption></figure></div>

Каждый день Скупец предлагает вам выполнить одну **Ежедневную сделку** — заработать определённое количество монеток, торгуя товарами из указанной категории. В качестве награды за выполнение сделки вы получите **одну случайную награду из доступного списка**.

### Показатель ежедневности

**Показатель ежедневности** — это система прогресса, которая увеличивается за выполнение **Ежедневных сделок**. Она состоит из **12 делений** и изначально равна 0.

{% hint style="info" %}
За заполнение делений **Показатель ежедневности** повышает уровень **Ежедневных сделок**: чем больше делений заполнено, тем **сложнее становятся задания**, но вместе с этим увеличивается и ценность возможных наград. Конкретная награда определяется случайным образом из набора, соответствующего текущему уровню показателя.
{% endhint %}

{% hint style="info" %}
**Показатель ежедневности** увеличивается за выполнение **Ежедневных сделок**: после первой выполненной сделки заполняется первое деление, а затем новое деление добавляется **за каждые две выполненные сделки**. Всего показатель можно увеличить до **12 делений**.
{% endhint %}
