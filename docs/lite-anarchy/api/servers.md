# Список серверов

**Список серверов** - эндпоинт, возвращающий перечень доступных серверов и их системные идентификаторы.

## Запрос

**URL:** `https://api.holyworld.me/v1/servers`

Параметры отсутствуют.

**Пример запроса:**
`GET https://api.holyworld.me/v1/servers`

## Ответ

Возвращает объект, где ключами являются ID серверов, а значениями - их отображаемые названия.

**Пример ответа:**

    {
      "LITE_ANARCHY_17": "СолоЛайт #17",
      "LITE_ANARCHY_18": "ДуоЛайт #18",
      "LITE_ANARCHY_60": "КланЛайт #60",
      "LITE_ANARCHY_40": "ТриоЛайт #40"
    }

| Ключ (Key)   | Тип    | Описание                      |
|--------------|--------|-------------------------------|
| Server ID    | string | Системный идентификатор       |
| Value        | string | Отображаемое название сервера |

Полученные идентификаторы используются в других запросах API.
