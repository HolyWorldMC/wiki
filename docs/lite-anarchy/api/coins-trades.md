# Сделки с койнами

**Сделки с койнами** - публичный эндпоинт API для получения данных об сделках с койнами.

## Запрос

**URL:** `https://api.holyworld.me/v1/coins-trades`

| Параметр | Тип    | Обязательный | Описание                          |
|----------|--------|--------------|-----------------------------------|
| limit    | number | Нет          | Количество последних сделок       |

**Пример запроса:**
`GET https://api.holyworld.me/v1/coins-trades?limit=5`

## Ответ

Эндпоинт возвращает массив объектов сделок.

**Пример ответа:**

    [
      {
        "rate": 3840009.0,
        "datetime": 1785955192000
      }
    ]

| Поле     | Тип    | Описание                      |
|----------|--------|-------------------------------|
| rate     | number | Курс конкретной сделки        |
| datetime | number | Время совершения сделки       |

Данные используются для расчета актуального курса валюты на бирже.
