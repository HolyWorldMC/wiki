# События серверов

**События серверов** - эндпоинт для получения списка активных игровых ивентов.

## Запрос

**URL:** `https://api.holyworld.me/v1/events`

| Параметр | Тип    | Обязательный | Описание                                                        |
|----------|--------|--------------|-----------------------------------------------------------------|
| server   | string | Нет          | ID сервера. Без параметра возвращаются события всех серверов    |

**Пример запроса (все серверы):**
`GET https://api.holyworld.me/v1/events`

**Пример запроса (конкретный сервер):**
`GET https://api.holyworld.me/v1/events?server=LITE_ANARCHY_31`

## Ответ

Структура ответа зависит от наличия параметра `server`.

### Без параметра server

Возвращает объект, где ключами являются ID серверов.

**Пример ответа:**

    {
      "LITE_ANARCHY_31": [
        {
          "instanceId": "9e210c69-ed7c-44d8-9774-3d94d064125e",
          "id": "MINE",
          "metadata": {
            "displayName": "Смертельная шахта",
            "rare": "default"
          }
        }
      ],
      "LITE_ANARCHY_32": [
        {
          "instanceId": "becc2001-3f99-484a-8bbd-3a969aa44aba",
          "id": "PARCELS",
          "metadata": {
            "displayName": "Посылка",
            "rare": "rare_desert"
          }
        }
      ]
    }

### С параметром server

Возвращает массив событий для указанного сервера.

**Пример ответа:**

    [
      {
        "instanceId": "9e210c69-ed7c-44d8-9774-3d94d064125e",
        "id": "MINE",
        "metadata": {
          "displayName": "Смертельная шахта",
          "rare": "default"
        }
      }
    ]

| Поле         | Тип    | Описание                      |
|--------------|--------|-------------------------------|
| instanceId   | string | Уникальный идентификатор      |
| id           | string | Тип события                   |
| metadata     | object | Дополнительные данные события |
| displayName  | string | Отображаемое название события |
| rare         | string | Редкость или тип события      |

## Использование

Для корректной фильтрации используйте идентификаторы, полученные через эндпоинт из servers.md
